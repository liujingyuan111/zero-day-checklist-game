# 更新记录

## 0.6.0 · 四向镜头

首夜街区支持 Q / E 绕角色转动 90°，鼠标滚轮从 55% 拉远到 175% 拉近。WASD、点地寻路、建筑拾取和地标跟随当前视角。空间感知改为 F。

## 0.5.0 · 雨夜

首夜 HUD 显示生命、饥饿、潮湿和 SAN。防雨毯、罐装粥和燃料分别影响淋雨、进食和回屋烘干。空间感知消耗 SAN。结算显示搜刮、进食、守夜和生命变化，支持生还、倒下与重开。

## 0.4.0 · 第一夜

默认入口改为限额采购与首夜生存。加入固定斜俯视 3D 街区、一天一次的外出选择、可跳过的单次空间感知、可追溯的体温结算及重新采购。原「夜班急件」和交互测试场保留独立入口。

## 0.3.0 · 夜班急件

新增从值班室出发、备料修桥、入仓取药和回程签收的完整出勤任务。新增 Q 搜寻、车身拾取区与独立作业站位、材料一次扣除、桥面与碰撞同步切换、命中提示及三段任务指引。F1 可回到原交互测试场。32 项回归覆盖旧行为与新任务。

## 0.2.0 · 交互测试场

加入移动、寻路、拾取、连续动作、取消和动作生效帧验证。
